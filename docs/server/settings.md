# Server Dashboard and GUI Settings

These are two different interfaces. The **Server Dashboard** is the browser-based web frontend opened at `boss.php`; **GUI Settings** is the desktop IPTVBoss dialog used to connect an installation to that server.

- [Open the Server Dashboard](dashboard.md)
- [Configure the desktop GUI](gui-settings.md)

For the browser console’s administrative sections, see [Server Console](index.md).
