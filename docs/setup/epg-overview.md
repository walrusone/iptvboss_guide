# EPG & Mapping

An EPG supplies programme information. Mapping connects that information to the channels in your layout; generating output makes it available to your player.

| Task | Start here |
| --- | --- |
| Import programme data | [Adding an EPG Source](epg-sources.md) |
| Assign guide data to channels | [Mapping Channels](channel-mapping.md) |
| Inspect the programmes for an existing mapping | [EPG Browser](epg-browser.md) · PRO |
| Manage basic dummy guides and AED definitions | [Dummy Guides and Inventory](dummy-guides.md) |
| Change programme titles and descriptions | [EPG Layout formatting](epg-formatting.md#configure-the-epg-layout) |
| Publish one shared guide | [Universal EPG](universal-epg.md) · PRO |
| Generate and test the guide | [Creating Output](output.md), then [Connect a Player](connect-player.md) |

For event-aware sports channels, continue to [Sports & AEDs](../features/index.md). If expected programmes are missing, start with [Channels have no guide data](../troubleshooting/common-problems.md#channels-have-no-guide-data).
